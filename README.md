# Enterprise Network Infrastructure & Security Simulation

## 📌 Project Overview
This project demonstrates an enterprise-grade network architecture designed and configured with redundancy, high availability, strict security policies, and centralized management as part of the NTI Network Infrastructure Training Program.

## 🛠️ Key Features & Technologies
* **Routing & Switching:** Subnetting (IPv4/IPv6), VLANs, Trunking, Dynamic Routing.
* **Redundancy & High Availability:** HSRP (Hot Standby Router Protocol).
* **Security & Access Control:** Standard & Extended ACLs, Port Security, SSH Access.
* **AAA Architecture:** TACACS+ & RADIUS servers for centralized authentication.
* **Network Services:** DNS, HTTP, Mail Services, NAT/PAT.
